MAIN FEATURES:

1. TRACE ROUTE MODE
   - Button: "🔍 Trace Route"
   - Auto-trace to google.com
   - Display network hops in real-time
   - Color-coded results (green = success, red = timeout)
   - Show total hop count
   - Scrollable list view for results

2. SUPER FAST SCAN MODE
   - Button: "⚡ Super Fast Scan"
   - Input fields: Start IP and End IP (optional)
   - Multi-threaded scanning (auto-detect CPU cores)
   - Scan ports 80 and 8080
   - Real-time camera detection display
   - Filter: Only show cameras (hide regular web servers)
   - Detection types:
     * Camera - WEB SERVICE
     * Camera - WEB
     * Camera - Login
     * Camera - HIK Vision
     * Camera - DVR
     * Camera - IP Camera
   - Show: IP, Port, Title, Server, Type, URL
   - Progress bar during scanning
   - Save results to file

3. NEIGHBOURS CAMERA SCANNER
   - Button: "📷 Neighbours Scanner"
   - Auto-detect local subnet
   - Scan all 254 IPs in subnet
   - Detect RTSP cameras (port 554)
   - Identify camera brands:
     * Dahua cameras (port 37777)
     * Hikvision cameras (port 8000)
     * Generic RTSP cameras
   - Display: IP, Camera Name, RTSP URL
   - Progress indicator
   - Save results to file

4. NETWORK INFORMATION
   - Display Local IP address
   - Display Router Gateway IP
   - Show current time
   - Network status indicator
